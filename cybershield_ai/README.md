## 🚀 Quick Start

### Prerequisites
```bash
# System requirements
- Python 3.11+
- 16GB+ RAM (32GB recommended)
- 100GB+ storage
- GPU (optional, for AI acceleration)
```

### Installation
```bash
# Clone repository
git clone https://github.com/cybershield-ai/platform.git
cd cybershield-ai

# Setup environment
python -m venv venv
source venv/bin/activate  # Linux/macOS
# or
venv\Scripts\activate     # Windows

# Install dependencies
pip install -r requirements.txt

# Download AI models
python scripts/download_models.py

# Initialize database
python scripts/init_database.py

# Start services
python main.py
```

### Docker Deployment
```bash
# Quick start with Docker
docker-compose up -d

# Access dashboard
open http://localhost:8080
```
